Bonzi Buddy v1.0.0

Install the animated purple gorilla in the ChatGPT desktop app.

Install Bonzi Buddy

Your browser may ask to open the desktop app. Complete installation there, then select Bonzi Buddy in Settings > Pets and use /pet to show it.

If the button does nothing, check that the desktop app is installed and the Pets feature is enabled. This launcher opens the documented install flow; it does not silently install anything.

For ChatGPT web, download the web sprite sheet and use Settings > Personalization > Pet > Select pet > Upload pet.
